# AI Game Comparison

A Next.js benchmark gallery for comparing small browser games generated by different LLMs. The app embeds playable Snake, Tetris, and Breakout runs, then shows the token usage and estimated generation cost for each model.

## What It Shows

- A home dashboard with model-level cost comparisons.
- Playable game pages for Snake, Tetris, and Breakout.
- Token and price ledgers for each generated run.
- Generated HTML games embedded safely into fixed-size iframes.
- Separate generation pipelines for Together and OpenRouter models.

## Tech Stack

- Next.js 16 App Router
- React 19
- TypeScript
- CSS Modules
- pnpm

## Getting Started

Install dependencies:

```bash
pnpm install
```

Run the development server:

```bash
pnpm dev
```

Open `http://localhost:3000`.

Build for production:

```bash
pnpm build
```

Start the production build:

```bash
pnpm start
```

## Generating Game Runs

Generated game data lives in `generated/` and is loaded by `lib/games.ts`.

To generate runs from Together models:

```bash
TOGETHER_API_KEY=... pnpm generate:games-together
```

To generate runs from OpenRouter models:

```bash
OPENROUTER_API_KEY=... pnpm generate:games-other
```

The scripts write these files:

- `generated/games.json`: Together-generated game entries.
- `generated/together-report.json`: Together generation success/failure report.
- `generated/openrouter-games.json`: OpenRouter-generated game entries.
- `generated/openrouter-report.json`: OpenRouter generation success/failure report.

Each generated entry includes the provider, model label, source model id, token counts, estimated USD cost, timestamp, description, and the generated single-file HTML.

## Project Structure

```text
app/
  page.tsx                Home dashboard and model cost overview
  snake/page.tsx          Snake comparison page
  [game]/page.tsx         Dynamic pages for Tetris and Breakout
components/
  comparison-page.tsx     Shared game comparison layout
  game-tile.tsx           Playable iframe tile for one generated run
generated/
  *.json                  Generated benchmark data and reports
lib/
  games.ts                Game definitions, data merging, display prep
  game-html.ts            Embedded HTML preparation and validation helpers
scripts/
  generate-games.mjs      Together generation pipeline
  generate-openrouter-games.mjs OpenRouter generation pipeline
types/
  game.ts                 Shared generated game entry types
```

## Notes for Maintainers

- `lib/games.ts` merges Together and OpenRouter output and normalizes entries for display.
- The Snake route has a dedicated page, while Tetris and Breakout use the dynamic `[game]` route.
- Generated HTML should be self-contained and must not depend on external assets, fonts, libraries, or network requests.
- Keep generated JSON committed when refreshing benchmark data so the app can run without API keys.
- Do not commit API keys or local environment files.
